# Student Registration & Result Portal

Mini project based on the supplied project brief.

## Features
- Student registration form
- Course selection
- HTML5 native validation using required, pattern, type, min and max
- Marks entry for four subjects
- Automatic total, percentage, grade and pass/fail result
- Responsive CSS3 layout using Grid and Flexbox
- Mobile-friendly navigation, cards, buttons and result table

## How to run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`, or open it with VS Code Live Server.
3. Fill in the form and click **Register & View Result**.

## Technologies
HTML5, CSS3, JavaScript


## Bootstrap 5
Bootstrap 5 CDN has been added for responsive utilities and components.
